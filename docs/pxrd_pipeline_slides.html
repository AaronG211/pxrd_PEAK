From a printed PXRD figure to trusted (2θ, intensity) data

A six-stage pipeline where computer vision owns the pixels, a vision-language model owns the semantics, and a deterministic verifier decides what to trust. This deck walks every stage — the algorithm, the parameters, the math, and the failure mode each step exists to defeat.

Aaron Gao · src/pxrd_fetcher/v2 · tools/
Overview

One principle, six stages

No single source is trusted. The LLM is brilliant at reading a figure but invents exact numbers; CV measures pixels precisely but can't tell a diffraction axis from a drawing. So every claim is cross-checked against a source that failed differently.

LLM · semantics

Is this PXRD? How many curves, what colors/labels, where's the axes box, what tick numbers are printed?

CV · pixels

Exact frame lines, tick-mark positions, the real ink of each curve, at working resolution.

Verifier · arbitration

Deterministic pixel-fidelity score decides accept/reject. Never asks the source that made the claim.

Result

Every accepted curve carries a full evidence chain: snap rate, precision, recall, calibration provenance.

Stage 1 — per pageLLM

Locate the PXRD panels

Each PDF page is rendered once and shown to the model with the page's text. The model returns a bounding box for every PXRD panel — and only PXRD, explicitly rejecting SEM/TEM, IR/Raman/NMR, TGA, isotherms, and schematics.

This is the cheap screening pass: one call per page, boxes in fractional page coordinates. It's also what the standalone "does this paper contain any PXRD?" scanner reuses.

Why a whole extra stage

A page is mostly not-PXRD. Locating first means the expensive per-figure work only ever runs on real diffraction panels.

Algorithm — llm.locate_panels
# page → 150 dpi, downscale to ≤1600 px page = render_page(pdf, dpi=150) page = downscale(page, max_dim=1600) # one vision call, JSON out panels = locate_panels(page, page_text) # → [{x0,y0,x1,y1}, ...] fractional # EXCLUDE: SEM/TEM, IR/Raman/NMR, # TGA, isotherms, schematics

in

page image + text

out

N fractional panel boxes

Defeats: wasting vision calls on the 80% of page area that isn't a diffraction plot.
Stage 2 — per panelCVLLM

Re-render at working resolution, then read deeply

Render. The panel is not cropped from the page bitmap — it's re-rendered straight from the PDF vector at an adaptive DPI so every panel arrives ~1500 px wide. A small panel on a page rendered at 300 dpi has tick marks only a few pixels tall; CV and OCR both fail there.

dpi = clamp( 72 · 1500 / clip_width , 220 … 900 )

Analyze. One vision call reads the whole figure at once and returns the semantic inventory used by every later stage.

Algorithm — _render_panel · analyze_figure
# vector re-render, adaptive dpi crop = render_region(pdf_clip, pad=12%) a = analyze_figure(crop) # a.is_pxrd bool # a.plot_box axes-frame rect (frac) # a.curves[] label · material · # sample_state · color · # is_stick_pattern # a.x_tick_values printed axis numbers # a.x_axis_title · grayscale_only · has_inset

The color word per curve becomes the identity anchor used later for both tracing and replot coloring.

Defeats: ticks/labels too small to detect (resolution), and the need for many small model calls (one deep read replaces several).
Stage 2⁺ — self-correctionCVLLM

Reframe an offset crop

The locate step sometimes returns a box shifted off the real plot — it clips the target on one side (losing high-2θ data) and pulls a neighbor panel in on the other. The returned plot_box reveals this: it touches a crop edge, or leaves a huge margin opposite.

  • Clipped side (plot_box within 0.03 of an edge) expands outward 0.65× the frame to reveal the true axis extent.
  • Other sides tighten to fixed label margins (L .26 · R .14 · T .14 · B .22) to trim the neighbor.
  • Both edges clipped on an axis ⇒ the frame already fills the crop ⇒ don't expand (would engulf neighbors).
Bounded + safety net
# at most 2 reframe passes if needs_reframe(plot_box): crop = render_region(reframe_clip(...)) a = analyze_figure(crop) # re-read # never make a figure worse: if reframed and result == REJECT: fall_back(original_crop)
Defeats: truncated high-angle data + neighbor-panel bleed from a mis-placed locate box — recovered e.g. 2–25° → 2–64° on one figure.
Stage 3 — per panelCV

Find the axes frame — by evidence, not by long lines

A multi-panel crop is full of straight lines (other plots, drawings, molecular structures). "Longest line" fails. Candidate frames are scored by axis evidence, and the search is restricted to the LLM's plot_box neighborhood.

Evidence score
  • tick marks below the bottom edge
  • numeric labels under those ticks (ticks without numbers = weak — defeats fake SEM-inset scale bars)
  • curve ink inside the box + a size prior

Many authors draw no full box — just a bottom axis. So each edge is classified, never invented.

Topology-adaptive — finalize_frame
# each edge is one of two kinds: VERIFIED contiguous stroke ≥ 65% of box height, within ±3.5% of the bottom-axis endpoint OPEN rebuilt from evidence, never from arbitrary ink: bottom-axis run ∩ LLM plot_box ± 3% ∩ tick evidence ± 1.4 gaps
Frame ladder
evidence-scored → hint-local → whole-crop # first candidate whose calibration # passes the trust bar wins
Defeats: phantom borders on borderless plots, stacked-peak columns masquerading as an axis, and welded neighbor axes (→ fake 70°+ peaks).
Stage 4 — per panelVERIFY

Calibrate pixels → 2θ by consensus

A pixel column maps to a 2θ value by a linear fit. But which pixels map to which numbers? Three independent sources answer, and calibration is trusted only when they agree.

2θ(x) = slope · x + intercept
  • CV tick-mark pixel positions
  • LLM printed tick values
  • OCR (pixel, value) pairs read off the strip

If sources disagree, the axis strip is magnified and re-read, then arbitrated. If nothing clears the bar, the figure is rejected — never guessed.

Decision — consensus_calibration
consensus two fits agree within 0.5° single one source, ≥3 pts, rmse ≤ 0.15° disagree / → retry: LLM re-reads axis strip weak → arbitrate: best err <0.5° & runner-up >1.0° failed → REJECT figure
Trusted output window
2θ range = tick extent ± 1.25 gaps ∩ frame physical extent

A trace beyond the outermost labeled tick is neighbor ink or hallucination — the drawn axis end is a hard bound.

Defeats: a single mis-read tick silently skewing every downstream 2θ; typical consensus rmse lands at 0.003–0.03°.
Stage 5a — per panelLLMCV

Trace each curve as an anchor polyline

A tick grid is drawn onto the crop, then the model is asked to trace each named curve as a coarse polyline in grid-fractional coordinates — 40–80 points per curve, all curves in one call. Naming each curve by its color + label makes the model follow the right one through overlaps.

The anchors are a shape hint, not the final data. They only have to be close enough for the pixel-snap step to lock onto real ink.

Algorithm — draw_grid_overlay · trace_anchors
grid = draw_grid_overlay(crop, frame) anchors = trace_anchors(grid, curves_desc) # per curve: [(x_frac, y_frac), ...] # 40–80 points, grid space # described as: "[red] TpPa-1 (exp)" # so overlapping curves stay separate

Curves the model fails to return are counted as failures later — they can't vanish silently.

Defeats: color-mask-only tracing, which loses a curve wherever two colors overlap. A semantic anchor survives the crossing.
Stage 5b — per seriesCVVERIFY

Snap to real ink, then verify against the original pixels

Each anchor point is snapped to the nearest real ink pixel, column by column. The ink mask is tried progressively — exact color first, then broader — and the best attempt wins by a blended score.

# mask ladder, retry until best color:{c} tol .045 → foreground .045 → fg-wide .09 score = 0.4·snap + 0.4·prec + 0.2·rec

Then a deterministic verifier compares the trace to the original pixels — non-circular, because it never asks the model that produced the trace.

Fidelity — vs original ink
snap_rate = anchors landing on ink
precision = traced points that are real ink
recall = real ink covered by the trace
Accept a series iff all hold
snap_rate ≥ 0.55 precision ≥ 0.70 recall ≥ 0.60 confidence ≥ 0.55
confidence =
0.30·snap + 0.30·prec + 0.25·rec + 0.15·(1 − dev/0.25)

Plus a ≥5° span guard and the 2θ-window guard — perfect scores over a sliver are meaningless.

Defeats: plausible-but-wrong traces. The check is against the photograph, not the model's own claim.
Stage 6 — per figureVERIFY

Decide, then turn pixels into a physical pattern

Figure verdict
  • accepted — every traced series passed
  • partial — some passed, others explicitly rejected
  • rejected — none passed

Figure confidence = mean of accepted-series confidence. Every rejection carries a reason string.

Then, per accepted series

The raw pixel trace is converted to a clean (2θ, relative-intensity) curve through a fixed post-processing chain.

Post-process — process_curve
1 baseline_asls(lam=1e7, p=.01, 10 iter) 2 subtract baseline, clip negatives 3 zero-anchor at 5th percentile 4 normalize_intensity → 0–100 5 interpolate to uniform 0.02° grid 6 savgol_filter(window=11, poly=3) 7 write CSV: two_theta_deg, rel_intensity
ALS: minimize  Σ wᵢ(yᵢ−zᵢ)² + λ Σ (Δ²zᵢ)²

This chain is per-series and non-linear, so it is irreversible — you cannot recover pixel rows from the CSV. That fact shapes the replot step next.

Output: per figure — result.json (full evidence), crop.png, overlay.png, one CSV per accepted curve.
Replot — offline, no APICV

Redraw each curve — faithful color without the pixels

Because the intensity transform is irreversible, the replot is drawn from the CSV, not the pixels. The hard part is color: the LLM's color name ("purple") is reliable, but the exact shade is not.

So identity comes from the name, and the shade is sampled from the original figure's actual ink — k-means clusters inside the plot box, in LAB space (perceptually uniform).

  • Unique color name → nearest ink cluster = faithful shade.
  • Duplicate name (author drew same-color stacked curves) → a qualitative palette so every curve stays distinguishable.
Algorithm — color_sampler · qa_montage
# isolate ink inside plot_box ink = saturated(S≥55,V≥45) OR dark(V≤110) minus white paper # perceptual clustering lab = cvtColor(ink, RGB→LAB) clusters = kmeans(lab, k=n+3) # assign if name unique: shade = nearest cluster else: shade = palette[i] # distinct

Curves are offset-stacked (60 units) to match the journal figure's layout. Montage = crop | overlay | replot.

Defeats: a replot where three similar reds blur together, or where a guessed hex is nothing like the printed curve.
Downstream — offlineVERIFY

Three guard layers on top of the extracted data

Drop computed curves

curve_is_computed removes simulated / calculated / Pawley-refined / difference / AA-AB-stacking reference traces so the database holds only measured experimental data. Trusts the explicit sample_state; label text is fallback (so "AA stacking CTF-1" the material still counts).

Offline quality filter

Two zero-API layers: CSV waveform signatures (plateau→jump staircase, needle notch, sawtooth via plateau segmentation of the smoothed trace) + tracing evidence (precision <0.80 / snap <0.80 / residual >15 px). Any bad series quarantines the figure. Calibrated on a 250-figure human audit.

First-peak feature

Denoised lowest-angle Bragg peak: SNR gate vs a rolling baseline · multi-scale persistence · FWHM window · edge/truncation flag. Each value carries a status (ok / low_confidence / truncated / no_bragg_peak) + d-spacing.

Everything is tiered, nothing deleted

Quality tier, match tier, first-peak status — downstream analysis filters by confidence rather than trusting a single flag. Every value is traceable to its source.

Known blind spot: geometric errors (3D-perspective plots, whole-axis mis-calibration) leave clean-looking CSVs — invisible to the offline filter, catchable only by eye.
Recap

The whole path, one line each

1 LOCATE page → PXRD panel boxes llm.locate_panels 2 RENDER vector re-render @ adaptive dpi + deep read _render_panel · analyze_figure 2⁺ REFRAME fix offset/clipped crop, safety-net fallback needs_reframe · reframe_clip 3 FRAME evidence-scored, topology-adaptive axes box select · finalize_frame 4 CALIB px→2θ, 3-source consensus within 0.5° consensus_calibration 5 TRACE LLM anchor polylines on a tick grid draw_grid_overlay · trace_anchors 5⁺ SNAP lock to ink + fidelity verify vs originals extract_series 6 DECIDE accept/partial/reject + ALS/normalize/smooth process_curve ↺ REPLOT LAB-sampled color, CSV → figure color_sampler · qa_montage

Every arrow is cross-checked by a source that fails differently. That is the whole design: measure twice with two kinds of eyes, and let a deterministic referee decide.
